# 🏎️ PITWALL — GP de São Paulo 2026

Landing page temática desenvolvida como projeto de estudo de **HTML5** e **CSS3**, inspirada no universo da Fórmula 1 e no Grande Prêmio de São Paulo no Autódromo de Interlagos.

---

## 📋 Sobre o Projeto

O **PITWALL** apresenta uma interface moderna em *Dark Mode* com alto contraste em vermelho (`#e10600`), tipografia esportiva e layout responsivo. O objetivo do projeto é praticar a estruturação semântica de páginas web, alinhamentos modernos e estilização de componentes complexos como tabelas e formulários.

---

## ✨ Funcionalidades e Seções

* **Navegação Fixa (Sticky Header):** Barra superior com acesso rápido às seções da página e botão de chamada para ação (*CTA*).
* **Hero Section:** Destaque principal do evento com estatísticas da pista (71 voltas, 4.309 km por volta, 15 curvas) e recorte diagonal estilizado com `clip-path`.
* **01. Grid de Pilotos:** Cartões individuais com identificação visual por cor de cada equipe (Ferrari, McLaren, Mercedes e Audi).
* **02. Classificação:** Área de filtros por nome/equipe e tabela completa de pontuação do campeonato.
* **03. Ingressos:** Tabela de valores por setor, alerta de disponibilidade e formulário completo de reserva (incluindo envio de foto para o telão e recado para o piloto).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Uso adequado de `<header>`, `<nav>`, `<section>`, `<article>`, `<table>`, `<form>` e `<footer>`.
* **CSS3 Moderno:**
  * **Variáveis CSS (`:root`):** Padronização de cores do tema e das escuderias.
  * **Flexbox & CSS Grid:** Organização responsiva dos cartões, menus e formulários.
  * **Estilização Avançada:** Uso de `clip-path`, `repeating-linear-gradient` (faixa quadriculada) e transições suaves.
* **Google Fonts:** Tipografia *Titillium Web*.

## 🚀 Como Executar o Projeto

1. Faça o download ou clone este repositório.
2. Certifique-se de que os arquivos `index.html`, `style.css` e a imagem de fundo estejam na mesma pasta.
3. Abra o arquivo `index.html` diretamente em qualquer navegador web (Chrome, Firefox, Edge, Safari) ou utilize a extensão **Live Server** no VS Code.
